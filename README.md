# Планёр

## Описание
«Планёр» – это программное обеспечение для автоматизированного планирования модельных экспериментов. Программа помогает исследователям, инженерам и студентам строить матрицы планирования для различных типов экспериментов без ручного перебора комбинаций факторов.

Пользователь выбирает тип эксперимента, задаёт количество факторов, их уровни и диапазоны значений, а программа автоматически генерирует таблицу с натуральными и кодированными значениями факторов, а также расчётным выходным параметром Y.

Поддерживаются следующие типы экспериментов:
- Полный факторный эксперимент (ПФЭ)
- Дробный факторный эксперимент (ДФЭ)
- Рандомизированный эксперимент
- Латинский квадрат
- Классический эксперимент

## Установка
1. Скопируйте папку с программой на компьютер.
2. Дважды щёлкните левой кнопкой мыши по файлу `Planer.exe`.
3. На экране появится главное окно программы.

Программа не требует установки (портативная) — достаточно просто запустить исполняемый файл. Специальная процедура инсталляции не требуется.

## Использование
Программа «Планёр» предназначена для автоматизации процесса планирования экспериментов в научных, инженерных и учебных целях.

В научных исследованиях она помогает сократить время подготовки планов эксперимента не менее чем в 3 раза по сравнению с ручным расчётом и исключить ошибки, связанные с человеческим фактором.

В образовательном процессе программа может использоваться студентами технических специальностей для изучения методов планирования эксперимента (DOE), освоения понятий «фактор», «уровень фактора», «кодирование значений», а также для выполнения лабораторных и курсовых работ.

В инженерной практике «Планёр» позволяет быстро перебирать различные стратегии планирования, находить оптимальные комбинации параметров и получать достоверные результаты при минимальных затратах ресурсов.

Основные возможности:
- выбор типа эксперимента из пяти доступных;
- ввод количества факторов (от 1 до 6);
- задание уровней (от 2 до 5) и диапазонов для каждого фактора;
- автоматическая генерация матрицы планирования в табличной форме;
- отображение натуральных и кодированных значений факторов;
- проверка корректности вводимых данных с выводом сообщений об ошибках.
